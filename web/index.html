ℹ️ How this works

            
The streaming TTS call returns the audio and per-word timings together, so the aligner is pinned to exact word boundaries — no ASR pass, no mishearing. Phone-level shapes come from Allosaurus; Fish's word spans stop it closing the mouth mid-word. Output is the Rhubarb cue format the game's VisemeTrack loads.

ℹ️ How this works

            
This is the same live call as the Call page — same agents, same session, same mic and error handling. Only the output is different: instead of an orb and bars, the agent's output level drives a VRM avatar's aa mouth shape, with an auto-blink, a gaze that follows this camera, and a slow idle sway. Nothing about the avatar is pre-rendered; it moves while the agent talks.
